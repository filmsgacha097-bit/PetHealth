PetHealth — Документация
=========================

**PetHealth** — десктопное приложение для ведения дневника здоровья
и медицинской карты домашних животных.

Возможности приложения:

* Ведение учёта питомцев (кличка, вид, дата рождения, заметки).
* Записи о здоровье (вакцинации, обработки, взвешивания, заметки).
* Медицинская карта — история болезней с симптомами и лечением.
* Справочник заболеваний и симптомов.
* Напоминания о предстоящих процедурах.
* Экспорт медицинской карты в PDF.
