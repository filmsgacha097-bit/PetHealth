Руководство пользователя
========================

Запуск приложения
-----------------

Скачайте файл ``PetHealth.exe`` и запустите его двойным кликом.
Рядом с файлом должна лежать папка ``assets``.

Вход в систему
--------------

* **Логин:** ``admin``
* **Пароль:** ``admin``

Для восстановления пароля нажмите **«Забыли пароль?»**.
Секретный вопрос: *«Кличка вашего первого питомца?»*,
ответ: ``мурка``.

Основные действия
-----------------

**Добавить питомца:**

1. На главном экране нажмите **«+ Добавить питомца»**.
2. Заполните поля: кличка, вид, дата рождения, заметки.
3. Нажмите **«Сохранить»**.

**Открыть карточку питомца:**

1. На главном экране найдите питомца.
2. Нажмите **«Открыть»**.

**Добавить запись о здоровье:**

1. Откройте карточку питомца.
2. Нажмите **«+ Добавить запись»**.
3. Выберите тип записи, дату, значение.
4. Нажмите **«Сохранить»**.

**Добавить заболевание:**

1. Откройте карточку питомца.
2. Нажмите **«+ Добавить заболевание»**.
3. Выберите болезнь из справочника.
4. Укажите дату начала, статус, лечение.
5. Нажмите **«Сохранить»**.

**Распечатать медицинскую карту:**

1. Откройте карточку питомца.
2. Нажмите **«Распечатать»**.
3. PDF-файл сохранится автоматически.

Решение проблем
---------------

**Приложение не запускается:**

Проверьте, что папка ``assets`` лежит рядом с ``PetHealth.exe``.

**База данных повреждена:**

Удалите файл ``pets.db`` и запустите приложение заново.

**PDF не создаётся:**

Проверьте наличие шрифтов в ``assets/fonts/``.
