# PetHealth — дневник здоровья домашних животных
 
Десктопное приложение для ведения дневника здоровья и медицинской карты питомцев. Позволяет хранить информацию о вакцинациях, обработках от паразитов, взвешиваниях, а также о заболеваниях с указанием симптомов, лечения и статуса.

## Возможности

- Добавление питомцев (кличка, вид, дата рождения, фото, заметки)
- Записи о здоровье: вакцинации, обработки, взвешивания, заметки
- Медицинская карта: заболевания, симптомы, лечение, статус
- Справочник заболеваний и симптомов
- Напоминания о предстоящих процедурах
- Поздравление в день рождения питомца
- Красивый интерфейс на CustomTkinter

## Технологии

- Python 3.9+
- SQLite (встроенная СУБД)
- CustomTkinter (графический интерфейс)
- Pillow (работа с изображениями)
- pytest (тестирование)
- flake8, black (чистота кода)
- Git (контроль версий)
