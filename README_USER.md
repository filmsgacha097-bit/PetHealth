# PetHealth — Руководство пользователя

Приложение **PetHealth** — дневник здоровья и медицинская карта
домашних животных. Позволяет вести записи о вакцинациях,
обработках, взвешиваниях и заболеваниях питомцев.

---

## Системные требования

- **Операционная система:** Windows 10 / 11, Linux
- **Свободное место на диске:** не менее 200 МБ
- **Оперативная память:** 2 ГБ или более
- **Разрешение экрана:** 1280×720 или выше

---

## Как запустить приложение

### Вариант 1. Запуск готового `.exe` (для Windows)

1. Скачайте файл **`PetHealth.exe`** из репозитория.
2. Поместите его в **любую папку** (например, `C:\PetHealth\`).
3. **Дважды кликните** по файлу `PetHealth.exe`.
4. Приложение запустится — откроется **экран авторизации**.

**Важно:** рядом с `.exe` должна лежать папка `assets` (иконки, шрифты,
анимация). Без неё некоторые элементы интерфейса могут не отображаться.

## Как пользоваться

### Вход в систему

- **Логин:** `admin`
- **Пароль:** `admin`

Это учебная демонстрационная авторизация.

### Основные действия

1. **Добавить питомца** — кнопка **«+ Добавить питомца»** на главном экране.
2. **Открыть карточку питомца** — кнопка **«Открыть»** на карточке питомца.
3. **Добавить запись о здоровье** — в карточке питомца кнопка **«+ Добавить запись»**.
4. **Добавить заболевание** — в карточке питомца кнопка **«+ Добавить заболевание»**.
5. **Редактировать питомца** — кнопка **«Редактировать»**.
6. **Распечатать медицинскую карту** — кнопка **«Распечатать»** (создаёт PDF).
7. **Справочник заболеваний** — кнопка **«Справочник»** в шапке.
8. **Напоминания** — кнопка **«Все напоминания»** в шапке.
9. **Восстановление пароля** — ссылка **«Забыли пароль?»** на экране авторизации.
Секретный вопрос: **«Кличка вашего первого питомца?»**, ответ: **`мурка`**.

## Устранение возможных проблем

### Приложение не запускается

**Причина:** отсутствует Python или зависимости.

**Решение:**
- Проверьте, установлен ли Python: `python --version`.
- Если Python есть — установите зависимости: `pip install -r requirements.txt`.

### Ошибка «ModuleNotFoundError: No module named 'customtkinter'»

**Причина:** библиотеки не установлены или установлены не в то окружение.

**Решение:**
- Активируйте виртуальное окружение.
- Установите зависимости: `pip install -r requirements.txt`.

### Ошибка «no such table: pets»

**Причина:** база данных повреждена или не создалась.

**Решение:**
- Удалите файл `pets.db` в папке с приложением.
- Запустите приложение заново — база создастся автоматически.

### Эмодзи отображаются как квадратики

**Причина:** на Linux не установлен шрифт эмодзи.

**Решение:** в приложении используются PNG-иконки вместо эмодзи,
поэтому проблема не должна возникать. Если что — переустановите
пакет `google-noto-emoji-fonts` (Linux).

### PDF не создаётся

**Причина:** отсутствует шрифт DejaVu Sans.

**Решение:**
- Проверьте, что папка `assets/fonts/` содержит файлы:
`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf`, `DejaVuSans-Oblique.ttf`.
- Если нет — скачайте с [dejavu-fonts.github.io](https://dejavu-fonts.github.io/).

### Приложение зависает

**Причина:** не хватает оперативной памяти.

**Решение:**
- Закройте лишние программы.
- Перезапустите приложение.
