# Бэклог продукта PetHealth

Список идей для будущих версий приложения.

---

## Новые функции

### Высокий приоритет

- **Уведомления о предстоящих процедурах.** Push-уведомления или всплывающие окна при запуске приложения, если приближается дата следующей процедуры.
- **Поиск по питомцам.** Поле поиска на главном экране для быстрого поиска по кличке.
- **Сортировка записей.** Сортировка записей о здоровье по дате (новые сверху / старые сверху).

### Средний приоритет

- **График веса питомца.** Визуализация изменений веса по записям о взвешивании.
- **Экспорт в Excel.** Выгрузка всех данных о питомце в формат `.xlsx`.
- **Резервное копирование БД.** Кнопка «Создать резервную копию» — копирует `pets.db` в отдельную папку.
- **Тёмная тема.** Переключение между светлой и тёмной темами интерфейса.

### Низкий приоритет

- **Загрузка фотографий питомцев.** Возможность загрузить реальное фото питомца (сейчас — PNG-иконки).
- **Поздравление с днём рождения питомца.** Всплывающее окно с анимацией шариков.
- **Мультиязычность.** Поддержка русского и английского языков интерфейса.

## Улучшения

- **Валидация форм.** Проверка корректности дат (`дд.мм.гггг`) перед сохранением.
- **Единый стиль иконок.** Использовать один набор иконок для всех элементов.
- **Автодополнение в справочнике.** При вводе названия болезни — подсказки из существующих.
- **История изменений.** Логирование всех операций (кто, когда, что изменил).

## Известные баги (исправленные)

- ✅ **Эмодзи не отображались на Linux.** Решено заменой эмодзи на PNG-иконки.
- ✅ **PDF не создавался с кириллицей.** Решено подключением шрифта DejaVu Sans.
- ✅ **Каскадное удаление не работало.** Решено командой `PRAGMA foreign_keys = ON`.
- ✅ **Восстановление пароля было небезопасным.** Решено через секретный вопрос.

---

## Известные баги (актуальные)

- ⚠️ **На Linux эмодзи-лапка в логотипе не отображается.** Требуется замена на PNG-иконку.
- ⚠️ **PDF-файлы сохраняются в корне проекта.** Можно сохранять в отдельную папку `exports/`.
- ⚠️ **Регистрация не сохраняет пользователей в БД.** Учебная демонстрация — можно внедрить полноценную таблицу `users`.
